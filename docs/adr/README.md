## Conventions
- Filename format: `NNNN-kebab-title.md`
- Status values: Proposed | Accepted | Superseded
- Required sections: Context, Decision, Consequences

## Rationale
ADRs preserve context behind technical decisions, enabling future contributors (human or AI-assisted) to understand the *why* and evolve safely.
