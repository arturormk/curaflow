# Code of Conduct

We follow the Contributor Covenant v2.1.

## Our Pledge
We pledge to make participation in Curaflow a harassment-free experience for everyone.

## Standards
- Use welcoming and inclusive language
- Be respectful of differing viewpoints
- Gracefully accept constructive criticism

## Enforcement
Report unacceptable behavior to the Maintainer (see `AUTHORS`). Sustained violations may result in temporary or permanent exclusion.

This project leverages AI assistance; treat AI-generated suggestions with the same respect as human drafts.
